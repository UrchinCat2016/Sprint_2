# Sprint_2

Финальный проект второго спринта курса Яндекс Практикума
«Инженер по автоматизации тестирования на Python — расширенный».

## Задания

- `task_1.py` — расширенный тест-кейс: наследование и `super()`.
- `task_2.py` — комедии и драмы: наследование и переопределение методов.
- `task_3.py` — спортивные очки: множественное наследование и статические методы.
- `task_4.py` — зарплата сотрудника: методы класса и альтернативные конструкторы.
- `task_5.py` — результаты футбола и хоккея: единый вызов методов в цикле.

## Запуск

Нужен Python 3. Внешние библиотеки не требуются.
Запускайте файлы из папки проекта, например:

```bash
python3 task_1.py
```

В заданиях 1, 2, 3 и 5 при запуске выводятся примеры из условий.
В `task_4.py` определён класс `EmployeeSalary`; примеры вызовов в условии
не заданы. Его можно импортировать в другой файл или в интерпретатор Python.
